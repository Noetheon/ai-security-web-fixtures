# Synthetic web-source fixtures

This folder contains six small synthetic deployment records: a harmless source and a prompt-injection source for three matched pairs across two mechanism families (authority claims in English and Chinese, and a mixed-language encoded instruction). They contain no company data, credentials, active code, embedded remote resources or callback endpoints.

A legitimate consumer extracts the ticket, window and source nonce as data; instructions in the fetched source must not replace the user task. Use commit-pinned raw-file URLs after publication. A retrieved nonce is a public source-binding marker, not a protected secret or an HTTP access log. Publication and local inspection do not establish execution or security coverage.
